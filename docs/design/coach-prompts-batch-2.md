# New ready-made coaches, batch 2 (D-115 follow-up)

The owner chose more ready-made coaches in the existing 3D style (2026-11-27) instead of a drawn customiser. Same way as the first 8 (asset-licences.md): make each portrait in **Google Gemini**, then the frame tool makes the 14 expression frames on the laptop.

## How to make each one

1. Open Gemini, start a **new chat** for each coach (so styles don't drift), and paste the coach's whole prompt below.
2. If it looks right (adult, friendly, mint background, green sweater, same 3D style as the first 8), download it.
3. Save it as `docs/design/coaches/<id>.webp` (or `.png`), using the id in the heading.
4. Tell Claude when some are in. Claude makes the frame sets and adds them to the app (`apps/mobile/tool/make_coach_frames.py`).

Keep each original download (the licence note in asset-licences.md still needs Gemini's commercial-use terms reviewed before the coaches ship, as for the first 8).

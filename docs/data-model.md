# Data model (Firestore)

Source: spec Section 11. Security rules: `firebase/firestore.rules` (T-FND-06, human review required).
Database: Standard `(default)` in nam5 per project (D-16). Every document carries `created_at`, `updated_at`, `schema_version`.
App code gets Firestore only through `firestoreProvider` (D-16).

| Path | Key fields | App (client) access | Written by server |
|---|---|---|---|
| `users/{uid}` | display_name, email, tz, locale, region, age_confirmed, onboarding_step (`avatar` → `voice` → `why` → `checkin` → `focus` → `plan` → `assessment`), focus_driver (≤ 40), focus_choices (1–2 of move_more, sleep_better, eat_better, less_stress, more_energy, healthy_routine; main first), activity_limited (bool, FR-GOL-03; absent when not asked), touchpoints {morning, midday, evening: "HH:MM"} (T-ONB-03e), coach_name (1–20), appearance {theme: system/light/dark, text_scale: 1.0/1.15/1.3}, quiet_hours {start, end: "HH:MM"}, notification_categories {greeting, nudge, reflection: bool} (T-ONB-03f), routine_mode {kind: travel/sick/busy, until: YYYY-MM-DD} or {kind: none} (T-GOL-03b), why_statement | Owner read; create only with `age_confirmed == true`; update listed fields only; no delete | plan_tier, ed_safe_mode, safety state; account deletion |
| `users/{uid}/consents/{id}` | type, doc_version, granted, granted_at, revoked_at, app_version, evidence_ref | Owner read; **append-only** create (created_at = server time); no update/delete | — |
| `users/{uid}/avatar/current` | **T-AVT-08b (schema_version 2):** `type: 3d_adult`, `source` (default \| selfie \| built), `coach_id` (one of 8 ready-made coaches: brown_hair, long_black_hair, green_hijab, navy_turban, grey_glasses, short_curls, short_black_hair, wheelchair), `coach_name` (1–20; absent = "Coach"), `background` (0–5), `raw_media_retained: false`; server-only: `frames_version` (a made-for-you frame set in Cloud Storage `avatars/{uid}/{version}/`: `avatar_frames.json`, `<frame>@2x.webp` / `@3x.webp` for the 14 frames, a frame that failed the quality check twice pointing at the neutral files, and `thumb_<expression>.png` 192 px thumbnails for notifications and the widget; T-AVT-08d), `options`, vendor ids, thumbnails. Older docs (`type: stylized`, `style_config`) still load: their background is kept and they get the default coach. | Owner read; the app creates/updates only a ready-made coach (`source: default`), its name and background; may switch a selfie/built coach back to default, never claim one; no delete | `frames_version`, `options`, selfie/built sources, vendor fields; deletion |
| `users/{uid}/voices/{voice_id}` | kind, vendor_voice_id, consent_id, status, speed, style | Owner read. **Library voices** (T-ONB-03c): the app creates them (`kind: library`, id `lw-…` from the app catalogue, status active/inactive, speed 0.8–1.2, style calm/energetic, fixed keys) and switches which one is active. Any voice: update speed and style. One active at a time (the app deactivates the others) | cloned voices: create, status, revoke |
| `voice_consents/{id}` | consent record (spec 11 example) | **None** | all |
| `users/{uid}/assessments/{id}` | bank_version, answers[], driver_scores, red_flags, map_result, completed_at | Owner read; create; update until completed; bank_version fixed | — |
| `users/{uid}/goals/{id}` | SMART fields, FITT, status, driver | Owner read/create/update; no delete (pause) | — |
| `users/{uid}/habits/{id}` | goal_id, title, anchor, window, size_variants, active | Owner read/create/update; no delete | — |
| `users/{uid}/habit_logs/{date_habitId}` | date, habit_id, status, source, size_done | Owner read/create/update; id must equal `date_habitId`; date and habit fixed | — |
| `users/{uid}/checkins/{date}` | mood (1–5, required), energy, sleep, stress (1–5, optional), time_available (2/5/10/30, optional), barrier_text (≤ 140, optional), source, gentle_day (bool) | Owner read/create/update; id `YYYY-MM-DD` (local date); created_at never changes; **mood ≤ 2 or stress ≥ 4 must have gentle_day = true** (T-DLY-02) | — |
| `users/{uid}/reflections/{date}` | text (1–500), prompt (`went_well`), source (`app`) | Owner read/create/update; id `YYYY-MM-DD` (local date); created_at never changes; no delete. Not in spec section 11 (added for FR-DLY-05 / T-UI-01d). Red-flag text is checked in the app and not saved | — |
| `users/{uid}/routines/{routine_id}` | name (1–40), days (1–7 of mon…sun), active (T-GOL-03a, My Daily Routine) | Owner read/create/update; id letters, digits, dashes (≤ 40); created_at never changes; no delete (pause with `active`) | — |
| `users/{uid}/routine_items/{item_id}` | routine_id, **either** catalog_id (approved list, `content/routine/catalog.json`) **or** custom: true, label (1–40), icon (fixed list), time "HH:MM", duration_min (1–180), days (optional override), reminder, avatar_announce, order. **One document per item (D-44)**, not an `items[]` list on the routine | Owner read/create/update/delete; an item never switches between catalog and custom; up to 12 a day is the app's limit (rules can't count). Custom labels pass the red-flag rules in the app first (GOL-03c) and are never spoken (FR-VOC-05) | — |
| `users/{uid}/routine_logs/{date_itemId}` | date, item_id, status (done/skipped), source (app/widget/notification) | Owner read/create/update; id must equal `date_itemId` (idempotent offline); no delete. Never counts for the streak | — |
| `users/{uid}/daily_plans/{date}` | next_step{title, reason, anchor, minutes 2/5/10/30, smaller_title, smaller_minutes, focus}, alternatives (≤ 2), supporting (≤ 2), mode (normal/gentle), day_number (1–7), source, template_version | Owner read. The app may create/update **starter** days only (`source: starter_v1`, fixed keys, T-ONB-03e) and never overwrite a day the server wrote; no delete | nightly plans |
| `users/{uid}/messages/{id}` | CoachMessage (spec 9.5) | Owner read only | orchestrator |
| `users/{uid}/memory_facts/{id}` | fact, category, confidence, source_message_id, status | Owner read; change status to saved/deleted only; deleted is final | Memory Agent proposals |
| `users/{uid}/streaks/current` | length, grace_used_week, best, restart_count | Owner read only | streak engine |
| `users/{uid}/portal_link/{doc}` | tagmango_customer_ref, matched_email_hash, status | Owner read only | link/unlink |
| `users/{uid}/portal_events/{id}` | event, offer_id, click_id, value | Owner read; **append-only** create of card_shown / clicked / dismissed | order / progress / completed (webhooks) |
| `portal_offers/{id}` | title, url, offer_type, tags, price_display, active, review_status | Signed-in read of active + approved only (queries must filter the same way) | Admin |
| `content_items/{id}` | lesson metadata, body, media | Signed-in read of approved only | Admin |
| `safety_events/{id}` | — | **None** | all |
| `audit_log/{id}` | actor, action, target, timestamp, ip_hash, details (no health content) | **None** | Cloud Functions; interim Firestore store (D-18), idempotent ids e.g. `consent_{uid}_{consentId}` |

Anything not listed is denied.

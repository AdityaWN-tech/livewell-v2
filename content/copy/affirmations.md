# Plan tab: daily thought (affirmations)

Status: **draft, needs human review** (tone, reading level, no health claims).
Shown on the Plan tab, one per day, picked by date so it stays the same all day
(`planAffirmation1`–`planAffirmation5` in `apps/mobile/lib/l10n/app_en.arb`).
Later the Coach Agent writes them (MY GOAL DO IT "Mindset", spec Appendix B); these
are the fallback.

Rules: short, kind, about 8th-grade reading level, never shaming, no promises
about health outcomes.

1. Focus on one small action today.
2. Small steps still count.
3. I don't need perfect. I need my next step. (from the spec's sample briefing, Appendix C)
4. Every restart is progress.
5. Today, I choose one thing that helps me feel well.
